# Cheatsheets

![License](https://img.shields.io/badge/License-GPL%203.0-blue.svg)

Printable cheatsheets I put together along the way, in French and English.
Browse them on [stranix.net/cheatsheets](https://stranix.net/cheatsheets/), or
straight from GitHub Pages below.

## Available

| Cheatsheet | HTML | PDF (A4 landscape) |
|---|---|---|
| Omarchy keyboard shortcuts (EN), for Omarchy 4.0 | [omarchy-en.html](https://stranix79.github.io/cheatsheets/omarchy/omarchy-en.html) | [omarchy-en.pdf](https://stranix79.github.io/cheatsheets/omarchy/omarchy-en.pdf) |
| Raccourcis clavier Omarchy (FR), pour Omarchy 4.0 | [omarchy-fr.html](https://stranix79.github.io/cheatsheets/omarchy/omarchy-fr.html) | [omarchy-fr.pdf](https://stranix79.github.io/cheatsheets/omarchy/omarchy-fr.pdf) |

Each cheatsheet is a single self-contained HTML file with a print stylesheet;
the PDF is what the browser prints, four columns on one A4 page.

## Contributing

Spotted a wrong binding or an outdated shortcut? Open an issue or a pull
request with the fix and the Omarchy version you checked it against.
